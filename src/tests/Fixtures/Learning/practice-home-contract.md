# Контракт данных учебного маршрута

Аккаунт получает модель через `GET /daily/api/today` с заголовком `Cache-Control: private, no-store`.
Гостевая модель вычисляется из компактного опубликованного каталога и прогресса этого браузера.
Идентификаторы `level` и `unit` в адресе `/daily` и запросе `today` соответствуют внешним идентификаторам каталога.
Если указан только `unit`, уровень берётся из оглавления. Без выбранной темы открывается тема незавершённого урока
или кандидата в пределах выбранного уровня, затем первая опубликованная тема этого уровня.

| Поле | Содержимое |
| --- | --- |
| `profile` | Текущий уровень, часовой пояс, ревизия. Для аккаунта также владелец, признак сохранённого профиля и настройки предложений. |
| `active_run` | Краткая карточка незавершённого прохождения любого вида. Приоритет у `in_progress`, затем у `paused`. Внутри статуса выбирается последнее начатое прохождение. Может быть `null`. |
| `candidate` | Следующий доступный урок текущего уровня или `null`. Карточка содержит `id`, `title`, `level`, `theme`, `duration_minutes` и краткую цель `goal`. |
| `route.level`, `route.unit` | Карточки выбранного уровня и темы с `id`, `title`, `path`, `status` и `reason`. Тема может быть `null`. |
| `route.lessons` | Карточки опубликованных уроков выбранной темы, дополненные `completed`, `review_only` и `run_id`. |
| `route.contents` | Оглавление уровней и тем с числом уроков по каждой теме. |
| `review_suggestion` | Доступное короткое повторение с фактическим числом заданий и оценкой в секундах или `null`. |
| `local_date`, `activity_today`, `exhausted` | Дата в часовом поясе профиля, признак активности за эту дату и отсутствие кандидата. |

`completed` соответствует фактическому завершению, `active` указывает на выбранное незавершённое прохождение,
`available` и `locked` отражают решение правил доступа, `unavailable` означает отсутствие опубликованных материалов
для выбранного уровня или темы. Доступ к нижнему уровню сопровождается `review_only`.
Решения берутся из `LearningAccessService` и `learningAccess.js`.
`active_run` имеет приоритет над `candidate` в главном действии.
В аккаунте `run` и `assignment` также используются для замены и восстановления ежедневного назначения.

Обычный запуск в аккаунте использует профиль из `today`. Запрос `POST /daily/api/runs` содержит ревизию и
`expected_owner_user_id`. Сервер проверяет владельца до записи и заново проверяет доступ при выборе версии.
Старт урока с маршрута передаёт `route_start: true`. Если под блокировкой владельца найден незавершённый run,
сервер подтверждает операцию с его состоянием. Гостевой старт делает ту же проверку в транзакции локального хранилища.
Экран прохождения загружает закреплённое состояние по идентификатору run. У гостя снимок запрашивается только при запуске урока.
Экран результата перечитывает `today` или гостевую модель для следующего шага. Новый run создаётся при явном запуске.
Контракт маршрута содержит метаданные опубликованных уроков. Снимки, задания, ответы и личный словарь в него не входят.

Хранилище объединяет параллельные загрузки для одного владельца и выбранной темы. История загружается отдельно
при открытии прогресса, словарь — при открытии словаря. Подтверждённые изменения инвалидируют модель и историю.
При смене владельца хранилище очищает представление и отбрасывает ответы старых запросов.
После ошибки новую загрузку инициирует пользователь или повторное открытие экрана.

Предложение на маршруте и в результате урока использует `review_suggestion`. Отказ действует до следующего
локального дня. Завершённый короткий блок скрывает предложение за день и при наличии помощи или ошибок.
Флаг `finished_today` описывает завершение блока, а `completed_today` сохраняет признак независимого успеха.
Ручной план доступен через `GET /daily/api/vocabulary/review-plan` с фильтрами словаря и не зависит от предложения.
Оценка времени учитывает типы выбранных вопросов и возможную длину аудио. Она округляется вверх до минут.
