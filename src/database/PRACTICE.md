## Почему в редакторском журнале 3980 строк

Импорт пишет отдельное событие на каждый предпросмотр и подтверждение пакета, на каждую обработанную версию занятия и на каждую редакцию каталога. Повторный импорт может обновить существующую версию и снова записать событие. В проверенной базе 2105 событий `session_import` относятся к 705 разным версиям. Публикация и изменение статуса пишут собственные события.

| Событие | Строк |
| --- | ---: |
| `session_import` | 2105 |
| `session_publish` | 706 |
| `import_preview` | 432 |
| `import_commit` | 422 |
| `catalog_import` | 150 |
| `catalog_publish` | 149 |
| `session_review` | 6 |
| `session_supersede` | 5 |
| `catalog_review` | 3 |
| `session_status` | 1 |
| `session_archive` | 1 |

Данные и индексы журнала занимали около 3,22 МиБ по оценке MariaDB. Срок автоматического хранения в коде не задан. Журнал нужен для истории действий редакторов и не используется для показа занятий или расчёта прогресса. Штатное удаление контента может удалить связанные события.

Две таблицы связей программ дублируют списки из JSON, однако текущий код зависит от их наличия. Проверка публикации, расчёт прогресса и переход между уровнями читают списки из `learning_curricula`. Импорт новой версии программы вызывает `objectives()->sync()` и `checkpoints()->sync()`. Обслуживание каталога выполняет прямые запросы удаления к таблицам связей. Внешние ключи ограничивают удаление связанных записей.

Повторная проверка выполнена на изолированной SQLite в памяти. Для исходной схемы успешно выполнены восемь сценариев. Затем каждая таблица временно удалялась внутри откатываемой транзакции и сценарии повторялись.

| Сценарий | Без `learning_curriculum_objectives` | Без `learning_curriculum_checkpoints` |
| --- | --- | --- |
| Импорт новой версии программы | Ошибка отсутствующей таблицы | Ошибка отсутствующей таблицы |
| Удаление занятия | Успешно | Ошибка отсутствующей таблицы |
| Удаление темы | Успешно | Ошибка отсутствующей таблицы |
| Удаление программы | Ошибка отсутствующей таблицы | Ошибка отсутствующей таблицы |
| Удаление уровня | Ошибка отсутствующей таблицы | Ошибка отсутствующей таблицы |
| Чтение целей через связь программы | Ошибка отсутствующей таблицы | Успешно |
| Чтение контрольных занятий через связь программы | Успешно | Ошибка отсутствующей таблицы |
| Чтение программ через обратную связь цели | Ошибка отсутствующей таблицы | Успешно |

Удалять эти таблицы при текущем коде нельзя. Для их устранения потребуется согласованно изменить импорт, обслуживание каталога, связи моделей и тесты, затем проверить целостность ссылок в JSON и выполнить миграцию. Пустые таблицы в проверенной базе соответствуют отсутствию импортированных программ. Рабочая схема в ходе проверки сохранена.

В третьей таблице связей, `learning_session_version_media`, колонка `session_version_id` указывает на версию занятия, а `media_id` — на аудиофайл. Эту связь читает публикация версии.
