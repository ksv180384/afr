# Озвучка словаря практики

Генератор работает в локальном профиле Docker Compose `audio`. Сайт на хостинге воспроизводит готовые MP3.

1. Запустите ComfyUI с узлами `qwen3-tts-comfyui` и моделью Qwen3-TTS Base 1.7B. В его каталоге `input` должны лежать выбранные `Lea_reference.flac` и `Paul_reference.flac` из workflow `V3_01_Create_Voices.json`. Их текст указан в `comfy.py`. При замене эталона запись и расшифровка должны совпадать.
2. В корне проекта выполните `docker compose --profile audio up -d --build pronunciation`. Адрес ComfyUI по умолчанию — `http://host.docker.internal:8188`. Другой адрес можно указать через переменную Compose `COMFYUI_URL`.
3. Войдите в локальную админку и откройте **Задания на сегодня → Озвучка** (`/admin/daily-practice/pronunciation`). Можно создать недостающие записи, прослушать оба голоса или заново записать слово. Массовая генерация обрабатывает весь словарь в фоне. Закрытие страницы не прерывает работу. После остановки и повторного запуска сервиса очередь восстанавливается из тома `pronunciation-queue`.
4. Скопируйте содержимое локального `src/public/practice-audio/` в `practice-audio/` под веб-корнем сервера с сохранением имён и вложенности. Для обновления отдельного слова достаточно заменить его MP3. Сопоставление идёт по французскому тексту и голосу, импорт в БД не нужен.

Формат — MP3, моно, 24 кГц, 48 кбит/с. Темп можно менять при воспроизведении. Каждый новый дубль использует тот же эталон с новым seed. Генератор публикует готовый файл после успешного кодирования. При обрыве связи с ComfyUI очередь ждёт подключения. Ошибку отдельного дубля можно перепроверить в таблице и повторить генерацию.
